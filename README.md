# Yosh Ekopatrul — Android ilova (2-bosqich)

1-bosqich (kamera) ustiga qo‘shilgan imkoniyatlar:
- suratga olish yoki galereyadan tanlash;
- surat rangi bo‘yicha dastlabki baho (sarg‘ish ranglar) + belgilarni tasdiqlash;
- 10 ta daraxt turi bo‘yicha ma’lumotlar bazasi (sug‘orish, tuproq, kasallik va zararkunandalar);
- sog‘lomlik foizi, holat (Sog‘lom / E’tibor kerak / Kuzatuvda) va tavsiyalar;
- daraxt profili, suratlar tarixi, qayta suratga olish;
- statistika va sozlamalar (ma’lumotlar qurilmada saqlanadi).

## Ishga tushirish
1. Android Studio → Open → `YoshEkopatrul` papkasi.
2. Gradle sync tugashini kuting.
3. Telefon/emulyatorda Run. Kamera ruxsatini bering.
4. APK olish: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Keyingi bosqich
Haqiqiy AI tahlili (turni va belgilarni suratdan avtomatik aniqlash) — server orqali model ulash.

Eslatma: natija taxminiy; aniq tashxisni agronom qo‘yadi.
